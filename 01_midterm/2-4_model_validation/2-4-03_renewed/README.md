# 2-4-03 Renewed — Raw Review Early-Warning Model

## 목표
정형 S45를 대체하지 않고, 원문 리뷰에서만 보이는 다음 달 저평점 급증의 조기 전조를
별도 텍스트 모델로 학습해 S45 위험도를 보정한다.

## 연구 원리
- DeepCoNN: 텍스트는 수백 개 수작업 피처가 아니라 별도 예측 신호로 만든 뒤 결합한다.
- NARRE: 같은 달의 모든 리뷰를 같은 증거로 보지 않고, 위험을 예고하는 리뷰를 더 크게 반영한다.
- Neu-Review-Rec: 월 전체 문서 신호와 개별 리뷰 신호를 역할 분담한다.
- Reviews4Rec: 강한 비텍스트 기준선(S45)을 유지하고, 텍스트의 순수 추가 기여만 채택한다.

## 고정 원칙
1. t월까지의 리뷰만으로 t+1월 위험을 예측한다.
2. 고정 부정 토픽 비율은 주력 입력으로 사용하지 않는다.
3. 텍스트는 '현재 불만의 양'보다 '상품 자신의 과거 대비 새롭고 강한 전조'를 찾는다.
4. 리뷰 수가 적을수록 텍스트 보정의 신뢰도를 낮춘다.
5. 기존 최종 Test는 이미 사용했으므로, 새 결과를 새로운 미관측 Test 성능으로 부르지 않는다.

- [ ] 4/8 원문 기반 텍스트 위험 모델 생성
- [ ] 5/8 리뷰별 중요 신호 및 월별 집계 생성
